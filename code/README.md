# code/

Analysis, figure and simulation scripts.

## Rules

1. **`run_all.sh` is the only supported entry point.** It must run end to end from a clean environment and print a value-by-value check against the manuscript.
2. **Prefix scripts with their execution order** (`01_`, `02_`, …). Any script not on the supported path lives under a clearly marked `deprecated/` directory with a README explaining what superseded it and why. *(The predecessor repository shipped a `run_all.sh` whose default path executed superseded scripts and printed an enrichment rate that did not match the manuscript. Do not repeat that.)*
3. **No absolute paths, no personal directories.** All paths resolve from a single `paths_config.py` (or equivalent) at the repository root.
4. **Figures are produced, not edited.** Every panel is generated by a script; hand-edited vector output is not accepted. If a figure was adjusted for layout, that adjustment is itself a scripted step.
5. **Random seeds are recorded** in the script header and re-asserted in `metadata/provenance.json`.
6. **One panel or one table per script** where practical, so that a reader can regenerate a single manuscript item without re-running everything.

## Layout

| Directory | Contents |
|---|---|
| `analyses/` | Scripts that produce the numbers reported in the manuscript and the Supporting Information tables |
| `analyses/recovered/` | Scripts recovered on 2026-10-02 from unarchived session directories, copied verbatim. Two of them **reproduce published values** (TOST / Newcombe). See its README before use — they carry hard-coded paths from 2026-09 |
| `figures/` | One script per figure panel; consumes `data/derived/` and writes to the runtime output directory. Read `figures/FIGURE_NUMBER_MAP.md` first — the scripts' internal figure numbers do **not** match the submitted paper |
| `simulations/` | The synthetic validation experiments (seed recorded in each header) |
| `deprecated/` | Superseded generations, retained only for provenance. Must never be reachable from `run_all.sh` |
| `deprecated/si_editors/` | The `.docx`-patching scripts that wrote the Supporting Information. They carry their values as **hard-coded literals** and read no data — they are an audit trail, not reproducibility material |
