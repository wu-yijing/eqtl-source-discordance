# eqtlgen_gene_universe.txt
#
# The gene universe the eQTLGen weight database was built over: the union of
# the analysis gene sets that this project scores on the eQTLGen arm —
#   * the housekeeping roster and its selection pool,
#   * the 104-gene testbed panel,
#   * the candidate / non-candidate / T2DM-control groups of the between-group
#     comparisons,
# taken together. 114 symbols.
#
# Why a checked-in list rather than a recomputation
# ------------------------------------------------
# The reported eQTLGen Z layer exists only for the genes that have a model in
# the source cis-eQTL file. Of these 114 symbols, 103 have a model and 11 do
# not (listed in the trailing comment). Filtering the source on these symbols
# is what reproduces the archived 65,622 weight rows; shipping the list makes
# the filter a fact about the archive rather than a fact about a directory
# that no longer exists.
#
# Do not "tidy" the trailing 11 away. They record the fact that the published
# tables carry 11 placeholder rows for genes with no eQTLGen model.
# ---------------------------------------------------------------------------
