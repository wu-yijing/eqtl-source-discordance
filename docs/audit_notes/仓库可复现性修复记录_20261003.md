## 二、逐条修复

### P0-1 `run_all.sh` 的 8 项 FAIL — 四个独立根因

| # | 根因 | 修复 |
|---|---|---|
| 1 | 7 个图件脚本读**前代文件名**（`gtex_official_Z.csv`、`primary_arm_96pairs_official.csv`、`scz_z_4arm_official.csv`、`gene_groups_TableS1_official.csv`、`eqtlgen_official_Z.csv`），而这些文件 2026-10-02 已改名进 `data/derived/`。`code/figures/paths_config.py` 里**没有**改名映射（`code/analyses/reproduction_20261002/paths_config.py` 里有） | 在 `code/figures/paths_config.py` 增加 `OFFICIAL_Z_RENAME` 与 `rz()`，7 个脚本改读 `P.rz(...)`。**不复制数据**——映射而非别名文件 |
| 2 | `run_all.sh` 预检 `grep -rqE 'data/processed[/"]'` 命中 `00_build_officialZ_data_layer.py` 的**注释与字符串字面量**（该脚本正是用来写弃用声明的），是**假阳性** | 改写那两处散文，使字面量不再呈现为路径；预检逻辑本身保留（它仍能抓真实引用） |
| 3 | `04_redraw_Fig8.py:64` `IndexError: arrays used as indices must be of integer (or boolean) type` | 真因不是数值类型：脚本按**前代 BMC 表号**取值（`S1`/`S2`/`S5`），而 GE 版补充材料把表整体位移一位（BMC S*n* → GE S(*n*+1)，原 S26 提到 S1），于是 `grid('S1')` 取到 Positioning 表 → 分组字典为空 → 掩码全假。加 `_TBL_ALIAS` 两套编号解析（优先 GE 号，回退前代号） |
| 4 | 同上一处的**次生**错误：GE 版 SI 用破折号 `—` 表示缺失值，脚本的一行 lambda `float(x) if x not in (None,'','NA')` 直接 `ValueError: could not convert string to float: '—'` | 在 `paths_config.py` 增加 `num()` 稳健解析器（占位符/千分位/百分号/自由文本一律返回 NaN），`04` 与 `08` 共用 |
| 5 | `08_redraw_Fig6_labels_20260920.py:67` `AssertionError: Table S5 ACAT columns not found` | 同因：该脚本按固定**表体序号**取值（`tabs[0/1/5/15/18]`），只对 2026-09-17 那一版 AF1 成立。改为按**题注解析表号** + 别名映射，两种 SI 都能跑 |

**修复后**：`bash code/run_all.sh` → **EXIT 0，零失败**，7 个图件脚本全部产出。

### P0-2 环境不可安装

| 缺陷 | 证据 | 修复 |
|---|---|---|
| `environment.yml` 锁 `python=3.13.0` + `numpy=1.26.4`，**无解** | 实测 `pip download numpy==1.26.4` → `No matching distribution found`（1.26.4 止于 2024-02，Python 3.13 起于 2024-10，无 cp313 构建） | 改为复现实际运行的栈：python 3.13.12 + numpy 2.4.4 / pandas 3.0.3 / scipy 1.17.1 等，**每个 pin 都先验证存在 cp313 wheel** |
| `requirements.txt` 全是下界（`numpy>=1.24.0` …） | 直接违反 `env/README.md` 第 1 条自己的规则；且与 `environment.yml` 和复现包 README 三方冲突 | 改为精确锁，三处版本号现在一致 |
| `Dockerfile` 四处路径/顺序错误 | ① `COPY environment.yml`（实际在 `env/`）② `chmod +x /app/run_all.sh`（实际在 `code/`，且被 `2>/dev/null \|\| true` 吞掉）③ `ENTRYPOINT ["/bin/bash","/app/run_all.sh"]`（该路径不存在）④ `renv::snapshot(lockfile='/app/renv.lock')` 在 `WORKDIR /app` **之前**执行，且会覆盖随仓库分发的 `env/renv.lock` | 逐一改正；R 层改为**从随包的 `env/renv.lock` restoren**；另 `apt-get install r-base-core=4.5.2-1` 在 Debian bookworm 无候选，改走 conda-forge |

> **未关闭**：`FROM continuumio/miniconda3:latest` 仍未锁 tag（`env/README.md` 第 1 条要求锁）。修
> 复时无法联网核对 Docker Hub 的可用 tag，**宁可留一个已知的开项，也不写一个没验证过的 tag**。
