## 1. 两条判据

### 1.1 尺寸是算术，不是谜

生成器 PDF 的页面为 `382.67999267578125 × 369.21600341796875 pt`：

```
382.67999267578125 / 72 * 600 = 3189.00  ->  3189
369.21600341796875 / 72 * 600 = 3076.80  ->  3077
```

发表栅格正是 **3189 × 3077**。matplotlib 自己的 PNG 写出器在这一位上与 PDF 页面**不一致**（它给 3188 × 3076）；PDF 栅格化器不会。故 3189 × 3077 不需要"另一个渲染家族"来解释，只需要"发表件是 PDF 栅格化来的"。

### 1.2 像素是对齐的

```
PDF @600 dpi            vs 发表件（改字前）   2,044 px   0.0208 %   rows (2331,2375) cols (510,751)
PDF @600 dpi            vs 发表件           20,364 px   0.2075 %   rows (2256,2384) cols (510,1931)
PDF @600 + patch        vs 发表件            2,044 px   0.0208 %   rows (2331,2375) cols (510,751)
```

- 0.2075 % 与 0.0208 % 之差（`20,364 − 2,044 = 18,320`）**恰等于** 2026-10-01 那笔改字所触碰的像素数（`FigS1_pre_patch.png → FigS1_published.png` 实测 **18,320 px**，记录值 17,589 px 系 `>12` 阈值口径），残差行区间 `y[2256,2384]` 与记录 bbox 一致。
- 与改字前栅格比只剩 **2,044 px**，全在**同一行文字**（`95% band (66.1-68.2%) -`，`rows 2331–2375 / cols 510–751`）。
- 该行两侧的**文字行带完全一致**（`(2150,2160) (2256,2309) (2332,2385) (2407,2449) (2479,2499)`），垂直互相关最优移位为 **dy = 0**（mean |Δ| = 0.529 灰阶），即**无位移、无缩放、内容相同**；差异是两个栅格化器对同一 PDF 的字形抗锯齿差。
- 与 PDF 相比，**直写 PNG 的问题不在内容而在相位**：整幅偏 9.5 %，且下采样（1/2、1/4、1/8）不降反升（11.1 % → 13.3 % → 16.8 %），是笔画级而非亚像素级的差。
