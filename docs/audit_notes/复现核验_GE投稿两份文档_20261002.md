## 四、两个"需补参数才逐位"的组

**（1）主臂 ρ 基因簇自助法区间 0.12–0.62** —— 种子与 B 已给出（20260915 / 10,000），但**未说明随机数发生器**：

| RNG | 复算区间 | 两位小数 |
|---|---|---|
| `numpy.random.RandomState`（MT19937） | [0.1161, 0.6220] | **0.12–0.62** ✓ |
| `numpy.random.default_rng`（PCG64） | [0.1121, 0.6258] | 0.11–0.63 ✗ |

12 个种子扫描：下端点均值 MT19937 0.1147、PCG64 0.1127，**恰好横跨 0.115 这个四舍五入分界**。→ 该区间在报告精度下可复现，**前提是表注写明使用 `RandomState`**。一致率区间不受 RNG 影响（离散统计量），12 种实现组合逐位相同。

**（2）基因标签置换的零分布 −0.22 ~ +0.23** —— 该值只有用**基因整块置换**（一次基因置换同时作用于三个表型）才能得到（MT19937 给 −0.218/+0.232）；而仓库 README 与 Table S17 附近的方法描述写的是 *Within each phenotype, eQTLGen Z-scores are permuted across genes*，按该描述复算得 **−0.199 ~ +0.199**，窄 0.02–0.03。两种口径的 P 都是「< 0.001」，结论不变，但**描述需与实现对齐**。
